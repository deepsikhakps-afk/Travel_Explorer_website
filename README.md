# 🌍 Travel Explorer

Travel Explorer is a responsive travel website that helps users explore popular tourist destinations, discover travel packages, and plan their next trip. The project is built using HTML, CSS, and JavaScript with a clean and user-friendly interface.

## ✨ Features

- Responsive design for desktop and mobile
- Attractive homepage with travel destinations
- Destination cards with images and details
- Search functionality
- Travel package section
- Contact section
- Smooth navigation
- Interactive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
Travel-Explorer/
│── index.html
│── style.css
│── script.js
│── images/
│── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` or open it in your web browser.
